# Обработка битов структуры NumStr (Qt Widgets)

Тестовое задание на C++ / Qt 5.15.2.

## Описание
Графическое приложение принимает четыре целых числа (`A`, `B`, `C`, `D`) в заданных диапазонах:
- `A`: 0 .. 256
- `B`: 0 .. 1
- `C`: -3 .. 60
- `D`: 10 .. 12345678

При нажатии кнопки «Выполнить»:
1. Значения сохраняются в упакованную структуру `NumStr` минимального размера (6 байт).
2. Структура преобразуется в массив байтов.
3. Каждый чётный бит массива инвертируется.
4. Каждый бит массива построчно записывается в выбранный пользователем файл (`0` или `1` на строку).

## Стек и сборка
- **Фреймворк:** Qt 5.15.2 (Qt Widgets)
- **Система сборки:** qmake
- **Компилятор:** MinGW 8.1.0 32-bit
- **Документация:** комментарии оформлены в стиле Doxygen

2. Собрать и запустить проект (`Ctrl + R`).
